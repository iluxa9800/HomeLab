# HomeLab

Практический проект по изучению системного администрирования и DevOps.

Проект создаётся постепенно. Каждая технология сначала изучается с точки зрения принципов работы, затем внедряется в домашнюю инфраструктуру и документируется.

Главная цель проекта — не собрать как можно больше технологий, а понять, как они работают и как используются в реальной инфраструктуре.

---

# Цели проекта

- изучение Linux
- изучение Windows Server
- понимание сетевого взаимодействия серверов
- получение практического опыта сопровождения инфраструктуры
- переход от системного администрирования к DevOps

---

# Подход к обучению

Во время работы над лабораторией каждая технология изучается по одному принципу:

1. Теория.
2. Практика.
3. Диагностика.
4. Разбор того, как это используется в реальной работе.

Главная задача — понимать, что происходит внутри системы, а не просто выполнять команды.
